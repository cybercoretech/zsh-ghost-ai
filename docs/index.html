02 / PREDICTION FLOW

Type naturally.
Ghost AI fills in the rest.

As you type, Ghost AI predicts your next command and shows it inline. Accept with →, dismiss with Esc. Nothing runs unless you say so.

01

Type a command

Start typing in your terminal as usual. Ghost AI watches your input without interrupting your flow.

git commit -m
02

Ghost predicts

Based on your history and context, Ghost AI suggests the likely completion in gray.

03

Accept or dismiss

Press → to accept the suggestion, or keep typing / Esc to dismiss. You're always in control.

05 / INSTALL

Install in one line

Drop it into your zshrc, restart your shell, and start typing.

$ curl -fsSL https://raw.githubusercontent.com/cybercoretech/zsh-ghost-ai/main/install.sh | bash
  1. Run the command above in your terminal.
  2. Restart your shell: exec zsh
  3. Start typing — press → to accept a suggestion.
